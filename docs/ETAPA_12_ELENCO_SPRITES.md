# Etapa 12 — Elenco de aprendizes em sprites

## Entregas
- Adicionados cinco spritesheets SVG: A02, A03, A04, A05 e A06.
- Mantido o personagem A01 como líder.
- Integrados os seis personagens ao sistema de animação existente.
- A horda escolhe entre A02 e A06 conforme a variação visual de cada integrante.
- Mantido o desenho procedural como alternativa caso algum SVG ainda não tenha carregado ou apresente erro.
- Atualizado o manifesto para identificar os seis spritesheets disponíveis.

## Padrão técnico
- Cada spritesheet mede 576 × 288 px.
- Grade de 6 colunas por 3 linhas.
- Células de 96 × 96 px.
- Estados configurados: corrida, salto, queda, repouso e comemoração.
- Uniforme laranja, calça azul-marinho e mochila; variações de pele, cabelo e cores de mochila.

## Validação
Os seis arquivos SVG, a configuração de animação e a integração no código foram consultados novamente no GitHub após os commits. Não foi executado teste em navegador ou dispositivo nesta etapa.
